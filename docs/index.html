[ Forensic Modules ]

Comprehensive On-Device Security Audit

[ DASHBOARD ]

Security Risk Dashboard

Calculates aggregate system risk (0–100) by evaluating Wi-Fi ADB status via getprop, granted Accessibility services, SELinux enforcement, overlay permissions, and banking package presence.

Engine: 0–100 Risk Scale & getprop ADB Verification
[ PERMS ]

Permission & Package Inspector

Queries package states via Shizuku dumpsys package. Categorizes dangerous permissions, highlights SYSTEM components, and exports structured security reports.

Source: dumpsys package & System App Tagging
[ CACHE_PURGE ]

External Cache Cleaner

Scans external cache directories with dry-run support, selective deletion, and 3-factor keyword confirmation ("PURGE"). EXTERNAL_CACHE_ONLY: internal /data/data remains untouched without root.

Scope: EXTERNAL_CACHE_ONLY
[ NET_SCAN + AI ]

Subnet Network Scan & AI Advisory

Performs parallel batch pings (~3s for /24) with ARP MAC parsing (/proc/net/arp). Integrates Gemini AI for advisor-only proposals and financial app deep scans governed by Policy Engine.

Target: Local /24 ARP Ping & Gemini Policy Engine
Also included:
[ WIFI_ADB · getprop + VERIFY_FAILED ] [ Banking Deep Scan ] [ Apps / Activities · confirm ] [ TRACE Audit Trail ]
[ Zero Trust Security Architecture ]

Strict Governance & Confirmation Tiers

VOID Auditor treats every execution intent as untrusted by default. Destructive operations (force-stop, app disable, data clear) require explicit human approval and pass through a structured security pipeline.

[ GOVERNANCE_RULE_01 ]

Gemini AI is Advisor-Only

Gemini proposes actions under Policy Engine oversight. AI never executes shell scripts directly; human confirmation is mandatory.

[ GOVERNANCE_RULE_02 ]

Key Storage & App-Private Logs

Gemini API keys are stored via EncryptedSharedPreferences. Audit trails (TRACE) log action, actor, risk level, and exit code in app-private storage.

[ GOVERNANCE_RULE_03 ]

Biometric / Device Credential Gate

Privileged features require optional BiometricPrompt or Keyguard device credentials (PIN/Pattern/Password) to block unauthorized local access.

[ GOVERNANCE_RULE_04 ]

3-Factor Confirmation for Purges

High-risk operations like cache wiping or app data clearing enforce dry-run verification, itemized selection, and explicit keyword typing ("PURGE").
